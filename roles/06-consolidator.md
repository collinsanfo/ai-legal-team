# Role 06: consolidator

Script first. Run `python scripts/build_pack.py path/to/pack`. It writes, with no AI:
- `drafts/questions-for-counsel.md`: the owner decisions to confirm (from `owner-decisions-to-confirm.md`
  if present), the red team's "needs counsel" rows, every `[COUNSEL ...]` marker by document and section,
  and the "Questions for counsel" sections of the research memos.
- `drafts/app-changes-needed.md`: known engineering tasks (from `known-fix-tasks.md` if present), extra
  changes from the owner's answers (from `owner-driven-changes.md` if present), and each document's
  "Code changes needed" list, or its `[APP CHANGE ...]` markers when it has no list.
- `drafts/law-research.md`: the memos' summaries, "not verified" lists and sources.
- `review.html`: every document on one page, markers colour-coded.

Use an AI consolidator only to polish the output (merge duplicate questions, order app changes by when
they are needed). Prompt:

You are the "consolidator" on {{BRAND}}'s AI legal team. Read {{PACK}}/drafts/questions-for-counsel.md and
{{PACK}}/drafts/app-changes-needed.md (generated by script). Merge duplicates, keep every distinct point,
group questions by topic, and give each app change a "when" (before the documents go live / soon after /
later) and a size (S/M/L). Do not add facts that are not in the pack. Save both files.
